# Pacman clone

A clone of the Pac-Man game I coded in **Java**, with all sprites drawn by me using **Procreate**.

## Features
- Hand-drawn characters and maze assets
- Pellet collection and scoring
- Collision detection and player movement

## Built With
- Java
- IntelliJ IDEA
- Sprites drawn in Procreate
- Git for version control
